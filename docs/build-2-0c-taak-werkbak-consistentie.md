# BUILD 2.0C — taak/werkbak consistentie

- Open centrale taak blijft operationeel leidend.
- Taakprioriteit wordt zichtbaar in de Vastgoedkansen-lijst.
- Alleen een open taak op een commercieel afgesloten dossier (`afgevallen` of `gepromoveerd`) geeft een read-only waarschuwing.
- `wachten` + open taak en `positieve_reactie` + open taak worden niet automatisch als inconsistent beschouwd.
- Geen automatische taaksluiting, statuswijziging, database-schemawijziging of Edge Function-wijziging.
